# JobPilot AI

An AI-powered job discovery automation built with **n8n** that streamlines the job search process from finding relevant listings to receiving instant alerts.

## 🚀 Workflow Overview

**Job Listings → AI Agent → Data Extraction → Relevance Filtering → Google Sheets → Instant Alert**

### 1. Scheduled Job Discovery

The workflow runs automatically on a set schedule to discover new job listings.

### 2. AI-Powered Data Extraction

An AI Agent processes job listings and extracts important information such as:

* Job Title
* Salary
* Requirements
* Job Details

### 3. Relevance Filtering

The workflow filters job listings based on predefined relevance criteria to identify suitable opportunities.

### 4. Google Sheets Logging

Relevant job opportunities are automatically stored in **Google Sheets** for organized tracking.

### 5. Instant Alerts

When a relevant job match is identified, the workflow sends an instant notification.

## ✨ Key Features

## 💡 Use Cases

JobPilot AI can help automate repetitive job-search tasks by:

* Finding new opportunities automatically
